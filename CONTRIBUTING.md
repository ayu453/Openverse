# Contributing to OPENVERSE

Welcome. OPENVERSE is built through transparent, respectful collaboration.

## Workflow
1. Read README and the documents in `docs/`.
2. Search existing issues before proposing a change.
3. For substantial work, open an issue or proposal first.
4. Fork the repository and create a focused branch.
5. Make a small, reviewable change and add tests where practical.
6. Run type checks, lint, and tests.
7. Open a pull request explaining the problem, solution, verification, and any privacy/security impact.

## Contribution credit
Contributors should receive accurate attribution. A contribution does not transfer ownership of unrelated work. Only submit material you have the right to contribute.

## Community standards
Be respectful, constructive, and patient. Harassment, discrimination, spam, doxxing, and exposing private information are not acceptable.

## Security
Do not publish exploitable vulnerability details in public issues. Use a private reporting channel when enabled.
